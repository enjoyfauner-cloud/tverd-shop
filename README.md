# Твердь — демо интернет-магазина инструмента

Демонстрационный сайт магазина строительного инструмента и крепежа: главная с баннерами, каталог с фильтрами, страница товара, корзина и оформление заказа. Всё работает в браузере, заказы никуда не отправляются.

Сайт — один файл `index.html`. Открыть: https://enjoyfauner-cloud.github.io/tverd-shop/

Фото товаров: положите снимок в папку `photos/` и добавьте товару поле `photo: "photos/<id>.jpg"` в массиве `P` внутри `index.html`.
